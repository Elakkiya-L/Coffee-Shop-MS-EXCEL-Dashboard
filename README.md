
### ☕ Coffee Sales Dashboard – Excel Project
## 📌 Project Overview

This project is an interactive Coffee Sales Dashboard built in Microsoft Excel to analyze sales performance, customer trends, and product insights.

The dashboard combines data from multiple worksheets using advanced Excel lookup functions and presents insights through Pivot Tables, Charts, and KPI Cards.

## 📊 Dashboard Features
Total Customers Analysis
Revenue Tracking
Quantity Sold Monitoring
Highest Revenue Country Identification
Most Sold Coffee Type Analysis
Top 5 Customers by Revenue
Revenue Trend Over Time

## 🛠 Tools & Techniques Used
Microsoft Excel
XLOOKUP
INDEX + MATCH
Pivot Tables
Pivot Charts
Slicers & Interactive Filters
KPI Cards
Data Cleaning & Transformation

## 📈 Insights Generated
United States generated the highest revenue
Arabica was the most sold coffee type
Revenue trends were analyzed across multiple years
Customer purchase behavior was identified using top customer analysis

Developed a professional Excel dashboard capable of transforming raw sales data into meaningful business insights using interactive visualizations and advanced Excel functions.
